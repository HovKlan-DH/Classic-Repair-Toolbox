Datasheets, service manuals and links for the selected board.

---

Two lists, both filled from the board's own data file:

* **Local files** - documents that came with the board data and are on your disk: service manuals,
  schematics as PDF, ROM listings.
* **Links** - pages worth knowing for this board, out on the web.

Each list is a table with a **Category** and a **Name** column, in the order the data file lists
them - the category tells the service documentation apart from the reference material.

Click a name to open it. Local files open in whatever application your system uses for that file
type; links open in your browser.

Nothing here is board-independent - switch board and the lists change with it.

## Something missing?

The lists come from the `Board local files` and `Board links` sheets in the board's Excel data file.
If you know of a resource that belongs here, it is a two-minute contribution - see
[Contribute data via CRT](Contribute-data-via-CRT).
