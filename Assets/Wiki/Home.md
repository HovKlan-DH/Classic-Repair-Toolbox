Documentation for **Classic Repair Toolbox** - everything that does not belong in the project [README](https://github.com/HovKlan-DH/Classic-Repair-Toolbox).

New here? Start with [Getting started](Getting-started). CRT explains itself as you use it, so this Wiki is short: installing, the features with more to them than a screen can say, and the reference pages.

Correcting a board, or adding a new one, is done on the "Contribute" tab, which walks you through it.

* [View boards from online source](View-boards-from-online-source) - see a board as everybody else sees it, without your own drafts
* [Maintainer tab](Maintainer-tab) - review and publish what others send in, for maintainers only
