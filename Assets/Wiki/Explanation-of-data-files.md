_CRT_ has many different data data files, where it will read its various information from, like hardware, board, components, highlights, schematic images and KiCad data etc. The "humanly written" data files are primarily Excel, which is used as the data format, as this is fairly straightforward for the most to work with.

Different files and folders:

* [Board Excel](Board-Excel)
* [Board JSON](Board-JSON)
