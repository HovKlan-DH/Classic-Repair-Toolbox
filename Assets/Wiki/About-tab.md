Who made this, where to find it, and who contributed the data for the board you are looking at.

---

The tab carries:

* The **version** of CRT you are running
* Links to the **GitHub project page**, the **fun-facts page** at
  [classic-repair-toolbox.dk/funfacts](https://classic-repair-toolbox.dk/funfacts/) and the
  **YouTube channel**
* An invite to the developer's **Discord** server,
  [Retro Hardware 2.0](https://discord.gg/kVTtdvZtzE) - accept the invite on the page it opens
* **Board Excel data last revisioned** - the date the board data you are using was last revised,
  useful when you are wondering whether a correction has reached you yet. Not shown for a board
  that carries no date.
* **Credits specifically for this board** - the people who gathered and checked its data, as a
  table with the columns "Category", "Sub-category", "Author / contributor" and "Contact for
  author / contributor". A contact that is a web page or an email address can be clicked. Not
  shown for a board with no credits.

The credits change with the selected board, since the data for each one was contributed by different
people.

The credits come from the board's own `Credits` sheet, and they list the main contributors only - as
the tab itself says, small contributions are not listed and a place here is for a "substantial"
contribution. If you have contributed a lot to a board, this is where your name can appear - see
[Contribute data via CRT](Contribute-data-via-CRT).
